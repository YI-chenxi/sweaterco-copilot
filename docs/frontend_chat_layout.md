# Chat layout and history navigation

Based on `integration/intent-enhancement` at
`cbe10328b57b9739241f9ad03f226f362e740547` (including PR #8).

## Changes

- Recent Chats renders every conversation in the current browser session,
  replacing the eight-item slice with an independently scrollable list.
- Short labels come from the first question and the first assistant reply's
  existing business metadata. Labels retain order IDs, quantities, categories
  and stages where available. They are not regenerated by later follow-ups.
  No additional model requests are made. Labels wrap rather than being clipped;
  hovering a history button shows the complete first question.
- The sidebar keeps Streamlit's native resize handle. Desktop width is constrained
  to 280–430 px. Workspace contains only a bottom Configure expander; model
  configuration hints stay inside that expander rather than the chat composer.
- User bubbles align right and assistant replies align left. Evidence, warnings,
  assumptions and actual business metrics retain their existing renderers.
- The composer uses root-level `st.chat_input`, pinned to the viewport bottom
  in empty, new and existing conversations, with its native embedded send button.
  Enter submits; Shift+Enter inserts a newline. The redundant API-key hint is removed.
- The existing evidence rail is retained. On narrower screens it stacks below the
  conversation and the composer uses the available width.

## Compatibility and scope

Streamlit's keyed containers and generated `st-key-` CSS classes require
Streamlit 1.39 or later. The dependency minimum is raised from 1.38 to 1.39;
the checked environment uses 1.66.1. No backend, business rules, shared contracts,
language switch, or model configuration logic is changed.

Conversation history remains session-local. This fixes access to existing older
conversations, not persistence across browser refreshes or server restarts.

## Verification

- Before this change: 434 existing tests passed on the current integration base.
- After this change: 445 tests passed, including native composer submission,
  reopening and resuming the oldest of twelve conversations, session isolation,
  first-exchange label stability, bilingual label length, and dual-task labels.
- Tests use mock model outputs and actual local CSV business tools; this is not
  a new measurement of live-model accuracy.

Run from the repository root:

```powershell
python -m streamlit run app/ui/streamlit_app.py
python -m pytest -q
```

Manual checks: create more than eight chats and scroll to reopen the oldest;
check a long or two-task title, sidebar resizing, right/left messages, Configure
placement, an empty new conversation, multiline input and the embedded send button.
