# PR Draft

## Title

`feat: add reproducible NLU evaluation and legacy comparison`

## Base

`integration/intent-enhancement`

## Description

Adds Person 2's reviewed 54-case ground-truth corpus and a reusable evaluation runner for the enhanced parser. The runner scores intent sequence, task intents, slots, missing slots, issue types, language, context slot updates, ambiguity, and empty-task outcomes; it isolates parser errors and protects existing report files.

Adds an optional comparison against the legacy `IntentParser` on the 40 single-turn, single-task cases the two parsers can both express. Legacy pass/fail uses only intent sequence, slots, and missing slots. Context, updates, multi-task handling, structured issues, and other enhanced-only behavior are outside the legacy score. Reports identify parser/prompt versions and hashes, model, dataset hash, timestamp, Git commit, and dirty-worktree status.

Includes live JSON/Markdown reports for the 54-case enhanced run and the 40-case legacy comparison, plus a failure analysis for Person 1. The reports show a dirty worktree in their metadata. They are traceable records of the runs, not results from a clean committed tree. Mock tests validate evaluator behavior and are not model accuracy claims.

No Parser, Prompt, shared contract, service, UI/API, or A1/A2 implementation is changed.
